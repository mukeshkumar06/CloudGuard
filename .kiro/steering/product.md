# Product: CloudGuard AI

The cloud security engineer your startup can't afford yet — that you can just ask.

- Users: engineers at startups and small teams who run AWS without a dedicated cloud security person.
- Experience: a voice-first, stateful briefing (simulated Alexa+ on an Echo-Show-style web client). The spoken answer is two or three sentences; detail goes on visual cards.
- Capabilities (v1): security intelligence, resource governance (ownership tags) and cost waste from resource state.
- Promise: every finding is backed by raw AWS evidence. CloudGuard explains and prioritises findings, and it changes nothing without explicit human approval.
- Hackathon: Alexa+ track (self-hosted MCP server, spec 2025-11-25, Streamable HTTP) plus the AWS Builder mini challenge. Deadline 2026-10-23 12:00 PT.
